05 / FAQ

Есть вопросы?

Коротко о том, что важно знать перед началом работы с Pary.

Для каких устройств доступен Pary?

Pary — Android-приложение. Проект использует Kotlin и Jetpack Compose. Версию для iOS сайт не обещает.

Можно ли пользоваться без Platonus?

Да. Основные разделы можно заполнять вручную. Подключение Platonus — дополнительная возможность, а не обязательное условие.

Где хранятся мои учебные данные?

Основные данные приложения сохраняются локально на устройстве. Для переноса предусмотрены экспорт и импорт резервной копии. При подключении внешних сервисов часть данных передаётся соответствующему сервису.

Как скачать приложение?

Открой страницу релизов проекта на GitHub. Там публикуются доступные сборки; подписанные релизные APK появляются только после успешной настройки подписи.

Можно ли посмотреть исходный код?

Да. Исходный код Android-приложения открыт в GitHub-репозитории проекта.
