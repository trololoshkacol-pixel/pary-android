Возможности

Всё для продуктивной учёбы

Pary объединяет все инструменты, которые нужны современному студенту, в одном красивом приложении.

📅

Расписание и обзор дня

Ежедневный обзор пар, занятий и дедлайнов. Всегда знай, что дальше.

📊

Оценки и посещаемость

Отслеживай свои оценки, записи об учёбе и посещаемость в реальном времени.

✅

Задачи и фокус

Встроенный менеджер задач и фокус-таймер для продуктивной работы.

🔄

Синхронизация с Platonus

Автоматическое подключение к Platonus LMS и фоновая синхронизация данных.

🔔

Уведомления и виджеты

Виджеты на домашний экран и умные уведомления — ничего не пропустишь.

🎨

Swiss Modern дизайн

Чистый, минималистичный интерфейс в стиле Swiss Modern. Приятно пользоваться.

Технологии

Современный стек

Pary построен на самых актуальных Android-технологиях.

  • Kotlin — основной язык разработки
  • Jetpack Compose — современный декларативный UI
  • Локальное хранение — данные всегда доступны офлайн
  • GitHub Actions — автоматическая сборка и тестирование
  • Открытый исходный код — полный доступ к коду на GitHub
// Pary Android
// Kotlin + Jetpack Compose

@Composable
fun ParyApp() {
  val theme = swissModernTheme()
  val schedule = rememberSchedule()

  Scaffold {
    DailyOverview(schedule)
  }
}
